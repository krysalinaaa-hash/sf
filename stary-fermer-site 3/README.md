# Старый фермер — сайт/MVP для проекта ВКР

Тема: «Разработка сервиса по доставке фермерской продукции напрямую от малых производителей к конечному потребителю».

Проект сделан как готовый статический сайт без внешних зависимостей. Его можно открыть в браузере, VS Code, PyCharm или любом другом редакторе.

## Что есть внутри

- Главная страница с позиционированием сервиса, метриками и описанием MVP.
- Каталог товаров с поиском, фильтрами, сортировкой и добавлением в корзину.
- Страница фермеров с карточками производителей и критериями отбора.
- Страница доставки с логистической схемой, FAQ и калькулятором стоимости.
- Корзина с изменением количества, расчётом доставки и оформлением демо-заказа.
- Кабинет фермера: добавление демо-товаров, статистика и список заказов.
- Собственные SVG-иллюстрации, логотип, карточки продуктов и фермеров.
- Адаптивная верстка под телефон, планшет и ноутбук.

## Как запустить

### Вариант 1. Самый простой

Откройте файл `index.html` двойным кликом в браузере.

### Вариант 2. Через локальный сервер

В терминале из папки проекта выполните:

```bash
python run_server.py
```

Откройте адрес:

```text
http://localhost:8000
```

Можно также запустить стандартной командой:

```bash
python -m http.server 8000
```

## Где удобнее работать

Для выбранного варианта используйте **PyCharm**. Проект можно открыть как существующую папку и запускать через файл `run_server.py`.

Сейчас это статический MVP на HTML, CSS и JavaScript. Такой формат удобен для демонстрации интерфейса и логики сервиса в ВКР. Если позже потребуется полноценный сервер, база данных и авторизация, проект можно расширить на Flask/Django — тогда PyCharm особенно пригодится.

## Примечание по шрифтам

В проекте используется современная CSS-настройка шрифтов: `Manrope`, `Inter`, `Segoe UI`, системные sans-serif и акцентный serif-шрифт для заголовков. Внешние файлы шрифтов не подключены, чтобы сайт работал без интернета и без проблем с лицензиями. При желании можно добавить Google Fonts или локально подключить выбранный лицензированный шрифт.

## Демо-логика

Корзина, оформленные заказы, заявки и товары в кабинете фермера сохраняются в `localStorage` браузера. Это имитирует работу сервиса без настоящей базы данных.

## Обновление фильтра фермеров

На странице «Фермеры» кнопка «Смотреть товары» теперь открывает каталог с параметром конкретного производителя, например `catalog.html?farmer=ivanovo`. В каталоге добавлен отдельный фильтр «Фермер», поэтому у каждого хозяйства отображаются только его товары, а не общий список.
