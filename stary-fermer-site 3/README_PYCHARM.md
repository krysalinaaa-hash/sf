# Запуск проекта в PyCharm

Проект «Старый фермер» — учебный сайт-прототип сервиса доставки фермерской продукции напрямую от малых производителей к конечному потребителю.

## 1. Открытие проекта

1. Распакуйте архив `stary-fermer-site-pycharm.zip`.
2. Откройте PyCharm.
3. Нажмите **File → Open**.
4. Выберите папку `stary-fermer-site`.
5. Дождитесь, пока PyCharm проиндексирует файлы.

## 2. Настройка Python

Для запуска локального сервера нужен установленный Python.

В PyCharm откройте:

**File → Settings → Project → Python Interpreter**

Выберите установленный Python или создайте виртуальное окружение.

## 3. Запуск сайта

Вариант 1 — через кнопку Run:

1. Откройте файл `run_server.py`.
2. Нажмите правой кнопкой мыши по файлу.
3. Выберите **Run 'run_server'**.
4. Откройте адрес, который появится в консоли, например:

```text
http://127.0.0.1:8000/
```

Вариант 2 — через терминал PyCharm:

```bash
python run_server.py
```

## 4. Какие файлы редактировать

```text
index.html              основная структура сайта
assets/css/styles.css   оформление, шрифты, адаптивность
assets/js/main.js       общие функции, корзина, формы
assets/js/catalog.js    фильтры и отображение каталога
assets/js/farmers.js    карточки фермеров и ссылки на товары
assets/img/             картинки, логотип, иконки
run_server.py           запуск локального сервера
```

## 5. Что уже работает

- каталог товаров;
- поиск и фильтрация;
- сортировка товаров;
- корзина;
- оформление демо-заказа;
- форма заявки поставщика;
- сохранение данных в браузере через localStorage;
- адаптивная верстка для телефона и компьютера.

## 6. Что можно добавить для диплома позже

- backend на Flask или Django;
- базу данных SQLite/PostgreSQL;
- регистрацию покупателей и фермеров;
- личный кабинет администратора;
- реальные статусы заказов;
- интеграцию оплаты и уведомлений.

## Обновление фильтра фермеров

На странице «Фермеры» кнопка «Смотреть товары» теперь открывает каталог с параметром конкретного производителя, например `catalog.html?farmer=ivanovo`. В каталоге добавлен отдельный фильтр «Фермер», поэтому у каждого хозяйства отображаются только его товары, а не общий список.

## Проверка выбора фермера

На странице `farmers.html` нажмите кнопку **«Смотреть товары»** у любого фермера.
Откроется `catalog.html?farmer=...`, и каталог покажет только товары выбранного производителя.
В левом блоке каталога также есть отдельный фильтр **«Фермер»**.
